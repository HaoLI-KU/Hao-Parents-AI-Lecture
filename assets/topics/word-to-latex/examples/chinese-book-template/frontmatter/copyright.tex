\chapter*{版本与使用说明}
\addcontentsline{toc}{chapter}{版本与使用说明}
\thispagestyle{plain}

这是一份\textbf{课程示例}，只使用虚构的设备、人物和数据，用来演示中文技术书的排版结构。

\begin{itemize}[leftmargin=1.6em]
  \item 版本：2026-11 示例版。
  \item 许可：仅用于课堂练习，可自行修改；不得把示例中的虚构数据当成真实技术资料。
  \item 模板范围：封面、版权页、前言、目录、图目录、表目录、正文、附录、参考文献、索引。
  \item 编译环境：XeLaTeX + biber + makeindex；字体使用 Fandol，便于在本机和 Overleaf 复现。
\end{itemize}

正式项目应把真实文件、来源记录和许可信息留在本机私有目录，不随公开仓库发布。
