## 爸爸｜认识两层 AI，用自己的 DeepSeek 账户跑通 Codex

### 1. 用两层来理解 AI

1. **界面是操作入口。** 你打开 Codex，在里面输入任务。
2. **模型负责生成回答。** 爸爸这台 Mac 的 Codex 接的是 DeepSeek。
3. **界面把结果显示给你。** 先试一句简单的问题，看看能否收到回复。
4. **最后自己核对。** 如果问的是事实，就对照原文。如果问的是操作，就亲手试一步。

### 2. 用自己的 DeepSeek 账户跑通 Codex

今天要做的是亲手从「有自己的账户」走到「在 Codex 收到一条回复，并能回开放平台找这次用量」。

1. **登录开放平台。** 在浏览器打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录爸爸自己的账户，按页面完成验证。打开账户余额和用量页面，记下测试前的余额与时间。
2. **小额充值。** 进入充值页面，先核对金额和账户。若页面允许，充约 10 元作为练习预算，支付后回到账户页确认余额。以页面实际可选金额为准，金额不合适就把这一步留待确认。
3. **创建 API Key。** 在「API Keys」创建一把专用于爸爸这台 Mac 的密钥，可命名为 `dad-codex`。它像给这个工具使用账户的一把钥匙。创建时在本机妥善保存。暂停屏幕共享，密钥只填入本机接入配置，避开聊天输入框、截图和课程仓库。
4. **把新密钥接到已跑通的 Codex。** 和家人一起确认这台 Mac 现有 DeepSeek 接入方式及密钥存放位置，保留可恢复的原设置，再把接入所用的密钥换成爸爸新建的那把。模型和接入地址先沿用已验证的配置。DeepSeek 官方方案使用 Responses API，配置示例将密钥存于本机配置文件。实际换密钥前先核对本机接入方式，勿共享配置文件或把备份存进课程目录。改好后完全退出桌面应用、重新打开 Codex，确认当前使用 DeepSeek 配置。若发现本机配置与预期不同，先按 [DeepSeek 官方 Codex 接入说明](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/codex/)核对，再决定是否调整现有配置。
5. **发一条短测试。** 在 Codex 新对话输入「请只回复：连接成功。」看到回复后记下发送时间。若提示认证失败，先核对密钥和当前配置。若提示余额不足，回开放平台检查余额。先修正原因，再发下一次测试。
6. **回开放平台核对。** 打开用量明细，选测试当天，若页面提供按 API Key 筛选，就选新建密钥和测试日期。用当时可见的时间、模型和用量粒度核对，页面只有汇总时就比较测试前后。读一读页面实际提供的输入、输出 token 和费用。Token 是模型处理文字时用的小单位，和屏幕上看到的字数可以不同。余额只显示到有限位数时，优先看用量明细。若暂时没看到记录，记下测试时间和密钥名称，下次刷新再查。

首课优先走到收到测试回复。用量还没核对到，或注册、支付、接入中途停住，就在第 2 节从该步骤继续。

### 3. 从手头的事挑入口

| 想做什么 | 先试哪个入口 | 一个生活例子 |
|---|---|---|
| 边看着 Mac 边问怎么操作 | 豆包 Mac 客户端的语音通话与屏幕共享 | 「怎么在 Finder 里快速看一眼照片？」 |
| 问问题、想办法、先看一段文字 | 在大陆优先用可用的 DeepSeek 或 Kimi 对话入口 | 「把这三件事写成一条发给家人的周末提醒。」 |
| 给一个练习项目做出或修改具体文件 | Codex | 「在练习目录新建一个能在浏览器打开的家庭菜单网页。」 |
| 把几份材料交给工作助手整理成一个成果 | 了解 ChatGPT Work 和 Kimi Work | 「把几份虚构菜谱整理成一张分类表。」首课认识用途即可。 |

这里按学习场景选入口。有的工具能做相似的事，课堂上先用最容易开始的那个。Codex 云端执行是运行位置的概念，和 ChatGPT Work 这样的工作入口分别理解即可。

## 妈妈｜把新 Mac 设置到能上远程课

本课按 macOS 27 编写。

### 1. 新 Mac 联网后先装豆包桌面版

1. 接电开机，按提示设置 Mac 登录密码并连网，打开 Safari。
2. 打开[下载豆包桌面版（Mac）](https://www.doubao.com/download/desktop?ug_utm_source=101)，选 Mac 版。下载后在 Finder 的「下载」里打开安装文件，按提示安装。从「应用程序」打开豆包并登录。
3. 在豆包桌面客户端先拨通语音通话，再从通话界面开启屏幕共享。若 macOS 提示授权，按提示在「系统设置 → 隐私与安全性」为豆包开启麦克风和屏幕录制相关权限（名称随 macOS 版本变化，例如「录屏与系统录音」），必要时重新打开客户端。按钮名称以现场版本为准。
4. 打开「系统设置」，对着 Mac 说：「请看我现在共享的画面。我想检查系统更新，请只告诉我下一步。」妈妈自己照着点，再让豆包按新画面给下一步。按豆包的说明，它会在收到指令时截取当时的共享画面。[豆包隐私政策](https://www.doubao.com/legal/privacy)
5. 做完停止共享并结束通话。进入账号验证或私人页面前先停共享。若通话或共享入口暂时不可用，记下卡点，先继续设置，第 2 节再补验收。

### 2. 检查更新，先把下载排起来

1. 打开「系统设置 → 通用 → 软件更新」。若安装需要重启，先看看等待时间。今天优先保证腾讯会议能入会，可先启动下载，或等入会测试后再重启。更新结束后重新检查这一页。
2. 从 Safari 打开[下载腾讯会议（Mac）](https://meeting.tencent.com/download/index.html)，选 macOS，先下载它。打开 Safari 的下载列表或 Finder 的「下载」目录，确认文件已下载完成。
3. 同时从 [MacTeX 下载页](https://www.tug.org/mactex/mactex-download.html)找到 MacTeX 安装包。它是大文件，网络和磁盘空间允许时让它先下载，等候期间做下面的设置。如果网络慢，先保腾讯会议和系统更新，MacTeX 可留在课间继续。
4. 用同样方法找到 [Chrome](https://www.google.com/chrome/)、[微信 Mac 版](https://mac.weixin.qq.com/)和 [ChatGPT 桌面应用说明](https://learn.chatgpt.com/docs/app)。优先下载后面马上用到的微信和 Chrome，ChatGPT 桌面端可接到第 2 节。ChatGPT 桌面端按现场界面确认 Codex 入口，沿用家里已验证的接入路线。官方下载或使用入口暂时不可用时，记下卡在哪一步，继续其他项目。

### 3. 登录 Apple 账户，检查 App Store 更新

1. 打开「系统设置」，点左上方 Apple 账户入口，用自己的账户登录并在自己的设备上完成验证。
2. 打开账户下的 iCloud 页面，核对日历、备忘录和照片等本次要使用的同步项目。家庭共享邀请与应用里的实际显示在第 3 节检查。邮箱账户在第 2 节另行添加。
3. 打开 App Store，点边栏的「更新」。如有待更新的应用，先更新马上要用的。其余在网络空闲时继续。回到更新页确认所选项目已完成。系统更新负责 Safari、备忘录等系统内建 App 的更新。App Store 的「更新」针对从商店获得的 App。

### 4. 安装腾讯会议，并亲手进会

1. 在 Finder 的「下载」打开官方安装文件。若是 `.dmg`，先打开，再看里面是可拖入「应用程序」的 App，还是要双击运行的安装器。若是 `.pkg`，双击后按安装器的提示继续。
2. 到 Finder 的「应用程序」打开腾讯会议。点家人发的测试邀请，开关麦克风，请对方确认声音。选择一个练习窗口共享，再停止。若被要求授予权限，按提示到「系统设置 → 隐私与安全性」检查麦克风或屏幕录制权限，按应用提示重新打开并试一次。
3. 退出会议，再用原邀请重新进会。Mac 还在更新时，先用手机验证能加入，再把 Mac 入会留作待办。
4. 打开「文本编辑」，写一行测试文字，试 `⌘C` 复制、`⌘V` 粘贴、`⌘S` 保存。把文件存到「文稿」，关闭后用 Finder 找回。

本节以能入会为优先。豆包试一次即可，其余软件先排下载，来不及就到第 2 节再安装。给每项软件记一个状态：待下载、下载中、已安装、已打开验证。
