状态：待审阅 · 腾讯会议

## 爸爸｜把真实需求写成可以核查的提示词

先补[第 1 节的 DeepSeek 接入与用量核对](01.md)。这节主要用大陆当地可用的 **DeepSeek 对话入口**（或已经确认能用的其他对话工具）。从下面三个生活场景挑一个真有需求的做完整一遍，有余力再换题。

### 写提示词时说清四件事

- **Goal（目标）**：我到底要拿这个答案做什么？
- **条件**：日期、地点、预算、适用人群或具体商品规格是什么？
- **来源和方法**：打开哪个网站、哪一页？找不到或打不开时，应该怎样报告？
- **输出和边界**：给我哪些字段，哪些信息要标「未核实」，哪些操作我自己做？

### 在爸爸的 DeepSeek 接入里认几个词

上面的提示词适用于 Chat。切到本机的 Codex＋DeepSeek 时，可以留意输入框附近的模型和推理强度选项。实际可选档位取决于接入配置和当前模型。

| 词 | 记住什么 |
|---|---|
| Model（模型） | 谁在生成回答。先确认当前会话使用的是哪一个 DeepSeek 模型。 |
| Reasoning effort（推理强度） | 当前模型支持时，控制愿意投入多少推理。简单整理用默认档即可。条件多、需要反复比较时，可以试高一档，观察是否更慢、答案是否真的更有用。 |
| Context（上下文） | 模型此刻能用的材料，例如当前对话、附上的截图、明确提供的网页正文。提示词里要指明看哪一份。 |
| Tools（工具） | 能不能联网、读网页或操作电脑，要看这个入口实际有哪些工具和权限。 |
| Tokens / Usage（用量） | 把本次输入、输出与开放平台的用量联系起来。不同会话的上下文不同，费用以平台明细为准。 |

DeepSeek 的 Responses API 会把多个界面档位映射到同一档。例如 medium、high、xhigh 都映射到 high，low 和 high 才适合作为一组对比。两个实际不同的档位可用时，可以把同一个便民信息问题放进两个新对话，保持模型和材料相同，只换推理强度。比较等待时间、遗漏的条件和能核查的证据。即使高档给了更详细的答案，也按原网页核对。看不到选项就继续用默认档。

[DeepSeek 官方 Codex 接入说明](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/codex/) · [DeepSeek Token 用量说明](https://api-docs.deepseek.com/zh-cn/quick_start/token_usage/)

### 练习 A｜在携程查往返机票

> 目标是比较往返机票。请查看携程公开可读的航班结果。出发城市是[城市]，到达城市是[城市]，去程可以在[日期范围]，返程可以在[日期范围]，[人数]人，[舱位]，[直飞或可转机]。列出最多三组结果，写清两程日期和机场、是否转机、票价币种及口径、能确认的行李条件、查价时间与结果链接。只能看到搜索摘要、旧页面或价格打不开时，请注明。到比较结果为止。

自己点开一组结果，复填日期和人数，核对两程机场和总价。看到的是「起价」时，在表里标出来。网站需要登录或不展示结果时，由自己在携程操作，把页面上看到的字段复制给 AI 整理。[携程](https://www.ctrip.com/)

### 练习 B｜在淘宝先搜对关键词，再比同一规格

> 我想买[商品]，需要[型号、尺寸或容量]，预算[金额]。先给三组可在淘宝复制使用的关键词，说明哪些词用来锁定规格。若能读到具体商品页，请比较同规格的选项，列出商品链接、所选规格、数量、运费和页面能确认的价格。领券价和到手价分开。看不到规格或结算条件就标待确认。

亲自在淘宝试一个关键词，点开两个同规格选项。先选中规格，再比数量和运费。有登录限制时，自己打开商品页，将选中规格与可见价格交给 Chat 整理。[淘宝](https://www.taobao.com/)

### 练习 C｜查上海或长宁的便民、就业或老年服务

> 请从上海市人民政府和长宁区政府网站查[我想了解的事项]。找到可打开的官方正文或办事指南。给我标题、发布单位、发布日期、能确认的有效期、适用人群、办理入口，以及支持每条结论的原文位置。把全市政策和区级服务分开。正文没写或无法确认是否现行的，标待确认。

自己打开官方正文，先核对域名和发布单位，再在页面找适用条件、生效日期和办理入口。若官方原文没支持 AI 的一句话，就把那句标成待核实。[上海市人民政府](https://www.shanghai.gov.cn/) · [上海长宁](https://www.shcn.gov.cn/)

### 让 AI 看网页，与让它操作电脑

先确认当前入口有搜索或读取工具。DeepSeek 官方 Codex 接入说明中，内置搜索默认关闭，文档所列方式要求支持搜索的模型（目前列为 deepseek-v4-pro）并配置 live 搜索。切换推理强度不会开启搜索。通过该配置发起的联网检索按 DeepSeek 的 Search API 规则计费。先给具体网址，请 AI 回报它实际读到的标题、日期和正文位置。若当前入口只有文字对话，自己打开网页，把相关正文复制给它。搜索摘要只能当线索。最后亲自点开来源，用浏览器页面查找核对至少一条结论。

网页由自己打开时，可用这条提示词：「下面是我从官方页面复制的正文。请只根据这段文字列出适用对象、办理条件和日期，每项注明依据在哪一句。正文缺少的写『待核实』。我会回到原网页逐条对照。」

若本机确实有可用的 Computer Use，可以由讲师做一次只读演示：「在指定浏览器打开这张公开页面，找到结果标题与页面链接，然后停下来。」OpenAI 对自家服务的功能介绍不能证明本地 DeepSeek 接入具备这个功能。默认用浏览器手动打开页面，由 AI 整理可公开的文本。只有爸妈的实际客户端和模型确认支持后才演示。登录、填写个人资料、提交订单和付款都由本人操作。Chat 的读网页练习可以独立完成。[OpenAI Docs：Computer Use](https://learn.chatgpt.com/docs/computer-use)

## 妈妈｜先验收应用，再做邮件和基础操作

### 检查应用和远程入会

1. 从上节链接进会。打开「下载」目录，逐项检查上节的状态。先完成系统重启和腾讯会议验证，再继续安装。
2. **Chrome**：打开官方安装文件，按窗口提示放入「应用程序」，再从那里打开，访问一个已知网页。**微信**：同样打开官方安装文件，安装后从「应用程序」打开，按提示用手机确认登录。先检查能看到聊天列表。
3. **复用 Mac 版豆包，检查 ChatGPT/Codex**：在 Mac 上发起豆包语音通话并共享练习画面，问「请看我现在的画面。我想找到邮件的获取设置，下一步点哪里？」照建议做一步，再停止共享。进入真实账户页面前先停共享。上节若没走通，先补麦克风和屏幕共享。另行确认 ChatGPT 桌面端的 Codex 入口。
4. **MacTeX**：下载结束后，从「下载」双击官方 `.pkg`，按安装器提示继续。成功后打开「应用程序」里的 TeX 工具目录，尝试启动 TeXShop。若仍在下载，就先做邮件。
### 添加邮箱并验证同步

1. **添加网易 126 邮箱。** 打开苹果「邮件 → 添加账户」，输入妈妈完整的 `@126.com` 邮箱地址。已添加的账号可在「邮件 → 设置 → 账户」查看。
2. **如果验证失败，检查客户端授权。** 打开[网易 126 网页邮箱](https://www.126.com/)并登录。在设置中找 POP3/SMTP/IMAP 或客户端授权相关选项，按网页提示检查 IMAP/SMTP 并生成授权码。先停止屏幕共享，再由妈妈将授权码填入苹果「邮件」的密码栏。菜单名称以实际账户界面为准。 [网易邮箱帮助](https://help.mail.163.com/)
3. **验证双向同步。** 从苹果「邮件」发一封测试邮件，在 126 网页邮箱的「已发送」里找同一主题。请家人回复，再回苹果「邮件」查看回信。需要调整检查频率时，打开「邮件 → 设置 → 通用 → 检查新邮件」。

快捷键和触控板集中放到第 3 节。

做不完时，先确保会议和邮件可用，记录还没验证的软件和动作。
