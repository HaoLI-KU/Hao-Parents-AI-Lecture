# 第 8 节｜启动技术手册与养花小站

状态：后续课草稿

## 爸爸｜用选好的模板搭建真实项目

1. 找回第 7 节的项目笔记、第一章材料位置和选好的 Overleaf 模板。先说清今天要搭到哪一步，例如「模板能在本机打开，能找到第一章放哪里」。
2. 在本机新建正式项目目录，保留一份原样模板。从模板页面核对使用条件，再将可用的模板文件放进项目工作副本。先找出主 `.tex`、章节文件和图表位置。能编译就先留一个原样 PDF，中文和字体等问题登记到待办。
3. 回看第 6 节的练习目录和四份规则。按实际模板的结构决定原始资料、章节、图表和输出放哪。先写 `AGENTS.md` 和 `guide/structure.md`，在入口里明确列出已经写好的规则及读取顺序。若还有余力，再把已确定的版式或语言偏好写入 `guide/formatting.md` 或 `guide/language.md`，未定的写「待定」。
4. 开一个新 Codex 对话，让它先说出读到了哪些规则、主文件在哪、第一章准备放哪。爸爸从 Finder 对照结果，确认后可加一个章标题或占位段落，再试着编译。做到能从现有文件继续即可。

可以这样交代 Codex：

> 这是我第一个真实技术手册项目。读者是［填读者］，模板是［填名称］，第一章是［填主题］。请先看模板已有目录，再对照第 6 节的结构规则。提议怎样保留模板的编译入口，以及新章节、素材和输出各放哪里。等我确认后，先写 AGENTS.md 和目录规则。已经决定的格式和语言偏好可记下来，缺的信息标待定。

## 妈妈｜用 Codex 做一个「我的养花笔记」

这周先做出一张网页，里面有两条示例养花记录。随后只改一条记录，看看网页怎样跟着更新。

### 第一步：把想要的网页说清楚

在「文稿」新建空文件夹 `plant-notes`，在 Codex 里选它作为当前项目。可以直接口述下面的提示词：

> 请在当前文件夹做一个简体中文单页网站，标题叫「我的养花笔记」。只创建三个文件：`index.html`、`plants.json`、`app.js`。HTML 放标题和卡片区域，样式简单清楚，写在 HTML 里。JSON 放两条示例记录：绿萝和薄荷，每条有名称、位置和观察笔记。JavaScript 用相对路径读取 JSON，把两条记录显示成卡片。用本机已有的工具启动仅本机可访问的预览，告诉我在浏览器打开哪个地址。如果预览需要额外安装软件，先告诉我。请只在这个练习目录工作，做到本地预览为止。

### 第二步：在 Finder 和浏览器里检查

| 文件 | 它负责什么 |
|---|---|
| `index.html` | 网页的结构，例如标题和卡片区域 |
| `plants.json` | 植物记录，像一张用固定字段写成的小表 |
| `app.js` | 读入植物记录，再把它们显示到网页上 |

1. 在 Finder 找到三个文件。请 Codex 给出本地预览地址，用浏览器打开，确认出现绿萝和薄荷两张卡片。网页通过本地预览读取 JSON，直接双击 HTML 时可能读不到数据。
2. 再说一句：「只改 `plants.json`，把薄荷的观察笔记改成『今天长出了两片新叶』。」刷新浏览器，检查只有薄荷的那条文字变了。
3. 看着 Finder 里的文件，说出下次要加一种植物应该改哪一个文件。以后想加照片或视频，可以从现有的卡片继续扩展。

本节做到本机可以预览、修改一条记录并看到更新。
