上一讲生成了第一份清单。这一讲不急着改图，先把「读得准」这件事做扎实：清单里的每个结论都要能指回文件里的某个 handle，覆盖报告里没有读到的部分要明确说出来。

### 1. 先看覆盖报告

打开 `inventory/<图号>.json`，看 `coverage`：

| 字段 | 含义 | 为什么要看 |
|---|---|---|
| `layers` / `layers_with_entities` | 图层总数与有实体的图层数 | 两者差太多，说明有大量空图层或图层表被清理过 |
| `block_definitions` / `block_inserts` | 块定义数与块引用数 | 定义多、引用少，可能有未使用块库 |
| `entity_types` | 出现过的实体类型数 | 类型太少要警惕代理对象或外部参照 |
| `xrefs` | 未绑定的外部参照 | 不为空说明图纸不完整 |
| `proxy_objects` | 代理对象数 | 大于 0 说明有 AutoCAD 自定义对象，几何可能读不全 |
| `texts` | 文字条数 | 与图纸上的文字量做直觉对照 |

再看 `warnings`。每一条要么解释清楚，要么在 `notes/` 里记下「为什么暂时不影响」。

### 2. 图层：清单 vs 图层管理器

1. 在 AutoCAD 打开原图，打开图层管理器，记下图层总数。
2. 对照清单里的图层表：逐一核对名称、颜色、线型、开/关、冻结、锁定。
3. 找一两个实体较多的图层，关闭其他图层，数一遍图元，和清单里的实体数对照。
4. 如果清单里有原图没有的图层，或原图有清单里没有的图层，先查是不是换了版本或打开了别的图。

### 3. 块、属性与位号

设备与仪表通常以块参照出现，位号在块的属性里。

1. 打开 `.md` 的设备、仪表清单，每条有 handle、TAG、NAME、块名和插入点。
2. 在 AutoCAD 里选中同一台设备，看属性面板里的 TAG 和 NAME 是否与清单一致。
3. 核对 `block_attrib_tags`：每个块的属性标签是否齐全；缺少 NAME 或 TAG 的块要单独记下来。
4. 抽 3 个位号，把 handle 记进笔记。下一讲做跨图核对时，handle 就是证据。

### 4. 文字与图框

1. 清单里的 `texts` 保留原始字符串、图层、位置和 handle；中文是 DXF 里的原文，不是渲染图上的字。
2. `title_block` 是标为 `TITLE` 图层的文字；如果你的图框在别的图层，用 `--title-layer` 重新生成清单：

```sh
.venv-cad/bin/python toolkit/cad.py inventory dxf/<图号>.dxf -o inventory --title-layer 图框
```

清单和审图页都支持 `--title-layer`；图框不在 `TITLE` 图层时，先按图层表确认它的图层名再重跑。

3. 图名、图号、版本、日期四项必须和原图逐字一致；有一位不同都要记下来。

### 5. 让 Harness 做一次「带证据的复述」

```text
当前工作区是 CAD-Review/。请只读 inventory/<图号>.json 和 .md，不要打开或修改 dxf/、original/ 里的图纸。
请按下面的顺序复述，每条都带证据（handle、文字原文或图层名）：
1. 这张图的图名、图号、版本、日期；
2. 图层完整性：图层总数、有实体的图层、零实体图层；
3. 块与属性：每类设备的块名、属性标签是否齐全；
4. 设备、仪表位号清单；
5. 文字里有没有明显的图框信息、说明、管线号；
6. 覆盖报告的缺口：外部参照、代理对象、空图层、编码或字体问题。
不要推断工艺连接，不要补猜缺失位号；文件里没有的写「无法从文件确认」。
```

### 6. 写一页「这张图读到了什么」

在 `notes/<图号>-阅读.md` 记录：

```markdown
# <图号> 阅读记录
- 文件与版本：
- 图层：共 __ 层，有实体 __ 层，零实体 __ 层
- 块：定义 __ 个，引用 __ 次；属性缺失：__
- 设备：__ 台；仪表：__ 个
- 图框：图名 __、图号 __、版本 __、日期 __
- 未解决：外部参照 / 代理对象 / 编码 / 字体 / 其他
- 我核对过的 handle：__
```

### 检查清单

- [ ] 能说清覆盖报告里每个字段的含义。
- [ ] 图层总数、有实体图层数与原图对照过。
- [ ] 抽 3 个位号，TAG、NAME、handle 与原图一致。
- [ ] 图名、图号、版本、日期逐字核对。
- [ ] `warnings` 每条都有处理或记录。
- [ ] 写完了 `notes/<图号>-阅读.md`。
- [ ] 没有把 AI 的推断当成文件事实。
