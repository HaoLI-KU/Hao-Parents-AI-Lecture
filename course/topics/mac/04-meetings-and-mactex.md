### 预定会议并同步日历

1. 在腾讯会议 Mac 客户端主页点「预定会议」，填主题和时间，再点「预定」。从会议详情或邀请菜单复制会议号和链接。把日期、时区与链接通过邮件发给约好的家人，请对方核对在哥本哈根看到的时间。
2. 在苹果「日历」建立测试日程，用日程右上角的彩色标记选一个自己可编辑的共享日历。双击日程，在「添加备注、URL 或附件」贴入会议链接。需要指定时区时，在「日历 → 设置 → 高级」打开时区支持，再点日程日期选择上海时区。请家人在哥本哈根用自己的设备核对当地开始时间，并打开链接确认是同一场会议。 [Apple 添加和修改日程](https://support.apple.com/zh-hans/guide/calendar/icalwr13-events/mac)
### 用微信输入法做语音输入

这一节的技术路径是**微信输入法（WeType）**，不是微信 App 聊天窗口里的语音转文字。微信输入法是独立的 macOS 输入法，装好后可以在任何输入框里用快捷键说话输入。

#### 先分清三个东西

| 名称 | 是什么 | 本课怎么用 |
|---|---|---|
| 微信输入法 | 独立的 macOS 输入法，可在任意输入框语音输入 | **本课使用** |
| 微信 App 的语音输入 | 微信聊天窗口里的语音/转文字功能 | 不作为本课路径，快捷键可能和微信输入法冲突 |
| macOS 听写 | 系统自带听写 | 只作备用；如果也用 Fn，要和微信输入法错开 |

#### 安装和设置

1. 打开[微信输入法官网](https://wetype.weixin.qq.com/)，下载 macOS 版并安装。
2. 打开「系统设置 → 键盘 → 文字输入」，确认微信输入法已经加入输入法列表；需要时切换到微信输入法。
3. 第一次使用语音输入时，按系统提示允许麦克风权限。
4. 打开微信输入法的设置，找到「语音输入」和「快捷键」。
5. 把语音输入快捷键设为 **Fn**。如果 Fn 被系统或其他软件占用，就在微信输入法里换成 Control 等组合，并把实际按键记下来。
6. 在语音输入设置里检查下面四项：

   - 是「按住说话」还是「按一下开始、再按一下结束」；
   - 有没有「免提 / 连续输入」模式；
   - 有没有「AI 整理 / 语音智能整理」；
   - 标点和中英文混说的设置。

   不同版本的界面可能不同，以本机实际显示为准。

目标是设成：**按一下 Fn 开始说话，再按一下 Fn 结束，文字进入当前输入框**。如果本机版本只有“按住说话”，就按住 Fn 说话、松手结束；场景 A/B 的验证目标不变。

#### 场景 A：在当前输入框说完就结束

1. 打开「文本编辑」或「备忘录」，点进正文输入框。
2. 按一下 Fn（或按住 Fn）开始说话。
3. 说一句中英文混合的测试句：

   > 明天给薄荷浇水，check the leaves。

4. 再按一下 Fn（或松手）结束语音输入。
5. 检查文字是否进入**当前输入框**，能否编辑、撤销。
6. 如果开启了 AI 整理，检查它有没有改掉原意；不要直接发送未核对的内容。

#### 场景 B：说话中途去桌面做别的操作

这是本课最重要的验证，练的是“语音输入不依赖当前窗口一直保持前台”。

1. 在「文本编辑」的输入框里按 Fn，开始说话。
2. 不要点进另一个输入框；只切换到 Finder、桌面或其他普通窗口，做一两步简单操作。
3. 观察语音输入是否还在继续，原来的输入框是否还在。
4. 回到「文本编辑」的输入框，按 Fn 结束。
5. 检查文字是否仍然进入原来的输入位置。

判断标准：

- 如果本机版本支持免提/连续模式，这一场景应能完成；
- 如果切走窗口后语音停止，记录实际现象，不要写成“已经成功”；
- 如果文字进了错误的输入框，说明焦点变了；回到原输入框再结束；
- 这场景对父母最重要，建议连续做两遍，确认不是偶然成功。

#### 避免和系统听写、微信 App 冲突

1. **macOS 听写**
   - 打开「系统设置 → 键盘 → 听写」；
   - 如果系统听写也使用 Fn，关闭它或改掉快捷键；
   - 本课只保留微信输入法作为主路径。
2. **微信 App 的语音输入**
   - 微信客户端的语音输入快捷键也可能使用 Fn；
   - 在微信设置里关闭或改掉与 Fn 冲突的语音输入快捷键；
   - 不需要关闭微信的语音消息功能，只要避免它抢同一个按键。
3. **其他输入法**
   - 使用前确认当前输入源是微信输入法；
   - 如果 Fn 被系统占用，按微信输入法设置换成其他键，并把实际按键记录在验收清单里。

#### 验收清单

- [ ] 能说出微信输入法和微信 App 语音输入的区别。
- [ ] 微信输入法已安装，并已加入 macOS 输入法列表。
- [ ] 麦克风权限已允许。
- [ ] 已确认 Fn 的实际行为：按住说话，或按一下开始/再按一下结束。
- [ ] 场景 A：说完后文字进入当前输入框。
- [ ] 场景 B：中途切到桌面其他窗口，回来按 Fn 后文字仍进入原输入框。
- [ ] 系统听写和微信 App 的冲突快捷键已关闭或改掉。
- [ ] AI 整理后的文字经过本人核对，没有直接发送。

### 验证 MacTeX

本节只用 Mac 上已经装好的 TeXShop，不需要 DeepSeek Harness。

1. 下载[中文手册练习项目（ZIP）](../../../assets/topics/word-to-latex/examples/chinese-manual.zip)和[测试文件](../../../assets/topics/word-to-latex/examples/mom-mactex-test.tex)。把 ZIP 解压到「文稿」，测试文件也放到同一个「文稿」位置。
2. 双击测试文件，TeXShop 会打开它。点工具栏的「排版」（Typeset），等预览窗口出现。若能看到「MacTeX 练习」和下面那行中文，说明中文编译环境可用。
3. 在 TeXShop 里打开解压后的 `chinese-manual/main.tex`。文件第一行指定 XeLaTeX，按「排版」编译；第一次目录可能为空，再按一次「排版」更新目录。
4. 在预览里核对封面、目录，以及「准备设备」「记录与复查」两个中文章节。看到本次生成的 PDF 就完成本节验证；妈妈本节不做 PDF 批注。
5. 若排版报错，先看 TeXShop 日志窗口的第一条错误，记下文件名和提示。确认 MacTeX 已安装、TeXShop 是从「应用程序」打开的；修不了就记下错误，下节课一起看。

如仍有待完成的基础操作，记下从哪一步接着做。豆包桌面版继续按需使用。工具选择与提示词的系统练习留到第 5、6 节。
