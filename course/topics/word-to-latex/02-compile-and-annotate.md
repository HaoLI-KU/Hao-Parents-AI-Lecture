这节使用虚构的两章中文 LaTeX 手册。目标是走通「打开项目、编译、定位批注、修改源文件、重新编译、核对 PDF」，再把方法带到自己的技术文档项目。

### 1. 打开练习副本

1. 下载[中文手册练习项目（ZIP）](../../../assets/topics/word-to-latex/examples/chinese-manual.zip)，在 Finder 解压到「文稿」。保留 ZIP 原件，只在解压后的 `chinese-manual` 副本里操作。
2. 在 DeepSeek Harness 打开整个练习文件夹，确认工作区指向解压后的副本。

把下面的任务交给 Harness。它应实际执行编译，并报告这次生成文件的位置。

```text
当前工作区是我刚解压的中文 LaTeX 练习副本。请先查看 main.tex 和 chapters/，找出编译入口与两章的引用关系。
使用本机已有的 MacTeX 和 XeLaTeX 编译主文件，并运行足够次数更新目录。请实际执行，报告本次生成的 PDF 路径和编译结果。
如果失败，先指出日志里第一条关键错误和涉及的文件，只在这个练习副本中做必要修复，再重试。需要安装软件或修改系统设置时先告诉我。
我会打开本次生成的 PDF，核对封面、目录和两个中文章节。
```

编译完成后，打开 Harness 报告的 PDF，核对封面、目录与两个中文章节。看本次编译结果和文件修改时间，避免误看旧 PDF。

### 2. 做一条带位置的批注

1. 在 Harness 预览里确认 `dsh-quote-annotate-pro` 已启用，选中封面标题，批注「改为『爸爸的技术手册练习』」。
2. 在批注清单确认所选原文正确，把批注发送到当前会话。

发送已选中的批注后，可以在同一会话继续交代任务。

```text
请读取我刚发送的 PDF 划词批注，先告诉我批注选中的原文、对应的 .tex 源文件和准备修改的文字。
等我核对位置后，只改这一处并重新编译主文件。请报告这次生成的 PDF 路径。
我会打开新版 PDF，检查标题已改变，目录和两个中文章节仍可读。
```

爸爸对照 `main.tex` 确认 Harness 找到的位置，再让它完成修改和重编。打开新版 PDF，核对新标题、目录和两个章节。若批注插件在本机无法定位，就直接给出 `main.tex` 与标题原句，按同样的定位和重编步骤完成练习。

### 3. 知道以后去哪里找模板

今天使用的是随课提供的中文 LaTeX 练习文件。下节课会和爸爸一起在 [Overleaf 官方模板库](https://www.overleaf.com/gallery)的 [Books 分类](https://www.overleaf.com/gallery/tagged/book)选一份喜欢的模板，再用虚构内容把它改成可编译的中文多章节技术书。今天只浏览版式和入口，不必立刻决定选哪一份。

本节以爸爸能在 Harness 预览中选中原文、提交批注，并在重新编译的 PDF 中看到新标题为完成。核对目录和两章仍可读。第 3 讲再选 Overleaf 模板，制作后续课程要用的中文技术书模板。
