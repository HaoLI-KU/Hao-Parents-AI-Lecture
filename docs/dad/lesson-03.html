Lesson 3 · 爸爸 · 腾讯会议

给 Codex 一个文件夹、一项任务、一个检查办法

本节步骤
  • 整理三个乱命名的文件
  • 同一句指令，看看权限有什么不同

第 2 节用 Chat 查资料、对比和核查结论。今天用 Codex，因为希望它在指定目录里实际改变文件，随后由自己检查。这节只做归档，LaTeX 放到第 4 节。

整理三个乱命名的文件

  1. 在「文稿」新建「AI练习」，里面建「归档原样」和「归档工作」。打开并保存这三个练习文件到「归档原样」：文件一、文件二、文件三。把三个文件复制到「归档工作」。
  2. 在 Codex 新开练习会话，选中「归档工作」作为项目目录。先发：

只读当前练习目录中的三个文本，按正文内容判断是什么。请先列出「原文件名 → 分类子目录/新文件名」，用正文日期和主题命名。内容不明确就标待确认。先给清单，等我确认再修改。

  1. 核对三个原文件都在清单里，分类分别与出行、购物、家庭日程匹配。选一个文件，自己打开原文确认日期和主题。改掉不满意的名字，再让 Codex 只按确认清单执行。保留扩展名和内容，遇到同名先停下。
  2. 用 Finder 打开三个子目录，数一数仍有三个文件，检查三个日期依次是 12 月 12 日、13 日和 14 日，再抽查一个正文。新文件名允许有不同写法，日期、主题和文件内容要对得上。若结果有误，从「归档原样」重新复制到空工作目录再练。

同一句指令，看看权限有什么不同

在 Codex 输入框下方找权限菜单。Ask for approval 通常允许在当前工作区内做常规操作，超出边界的动作可能弹出 Allow 或 Allow Once。Full access 允许 Codex 在本机更大范围内读写文件和运行联网命令，通常会省去这类逐次确认。桌面端可在「设置 → 通用 → 权限」启用 Full access 选项，再到当次会话的权限菜单选择。这里的审批和文件边界由 Codex 客户端控制，和 DeepSeek 推理档位是两回事。本机可能用不同的权限配置或隐藏 Full access。实验只对课堂副本；若该模式不可用，就用默认模式观察一次边界提示。

  1. 由家人陪同，在 AI练习 下准备两个空的相邻文件夹「权限练习工作区」和「权限练习输出」。只打开前一个作为 Codex 工作区，确认「AI练习」父目录没有同时获准写入，否则这个对比可能不会触发提示。两处都用课堂临时文件。
  2. 选 Ask for approval，发送：「只在同级的『权限练习输出』中新建 permission-test.txt，内容写『权限练习』。文件已存在就停下。别改其他文件，也别联网。」观察它是在请求一次批准、说明受限，还是能直接完成。若弹窗，先确认它只涉及这个临时文件。结束后手动清掉测试文件，恢复两处初始状态。
  3. 若本机允许，在新对话中选 Full access，打开同一工作区，发送完全一样的指令。观察是否需要点确认，再在 Finder 核对文件位置和内容。完成后结束 Full access 会话，并在下一次实际任务开始前确认权限已切回 Ask for approval。
  4. 说出你看到的区别。只在工作区内改名时，两种模式可能看起来一样，所以这里特意用旁边的空练习目录。Full access 减少确认弹窗，也扩大了可操作范围。即便任务能自己跑完，仍要检查结果。
