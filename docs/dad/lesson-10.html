爸爸的课程/第 10 节

Lesson 10 · 爸爸

从一张 DXF 开始，让 Harness 复述图纸事实

另存 DXF，用脚本把工艺流程图读成结构化清单，让 Harness 复述并核对

本节步骤

01先建一个只放工作副本的目录02在 AutoCAD 里另存为 DXF03备用：用免费转换器04准备 Python 环境05先在虚构示例上跑通06换成自己的一张图07让 Harness 只复述清单里的内容08亲手核对，再决定下一步09检查清单

第 9 节走完了 Word 转 LaTeX 的第一段。接下来换一种材料：多年积累的 AutoCAD 工艺流程图。这一条线的目标不是让 AI「看图猜意思」，而是让它读到图纸里的矢量数据——文字、块、图层、图框和位号，再和你一起核对、一起推敲。

今天只用一张图练手，原件不动；整理用的目录留在本机，不进课程仓库。

1. 先建一个只放工作副本的目录

在 Finder 的「文稿」里新建 CAD-Review/，按下面的结构放东西。原件永远只读，所有操作都在副本上做。

CAD-Review/
├── original/    AutoCAD 原件，只读，不覆盖
├── dxf/         从原件另存出来的 DXF
├── tools/       三个脚本（第 10 节下载）
├── sample/      虚构示例，先用来跑通流程
├── inventory/   结构化清单（脚本生成）
├── review/      审图页与批注（第 12 节）
└── notes/       每张图一份核对记录

这一步也可以让 Harness 做：在会话里说「当前工作区是 CAD-Review/，请只创建 original、dxf、tools、sample、inventory、review、notes 七个空目录，不要复制或移动任何现有文件」。

2. 在 AutoCAD 里另存为 DXF

DXF 是公开的矢量交换格式，AI 读它比读 DWG 稳得多。今天只另存一张图。

  1. 在 AutoCAD 打开要整理的那张图。先看清图号和图名，记在 notes/ 里。
  2. 选「文件 → 另存为」，文件类型选 AutoCAD 2018 DXF (*.dxf)，存到 CAD-Review/dxf/。菜单名称和位置以你本机版本为准；也可以在命令行输入 DXFOUT，在对话框里选同样的格式。
  3. 文件名用图号，例如 DEMO-PFD-001.dxf，以后台账、审图页和批注都用同一个名字。
  4. 若这张图引用了外部参照（XREF），先在 AutoCAD 里绑定再另存：用 XREF 命令打开外部参照面板，选「绑定」。未绑定的参照不会进入 DXF，清单会缺内容。
  5. 确认另存后没有覆盖原件；同目录下多出来的 .bak 或 .dxf 只是副本。

如果家里暂时没有 AutoCAD，或者某张图在 AutoCAD 里打不开，再走下面的备用路线。

3. 备用：用免费转换器

  1. 打开 ODA File Converter 官方下载页，选 macOS 13 以上、Apple 芯片的安装包。它是 Open Design Alliance 的免费转换器，首次打开需要同意许可。
  2. 启动后选输入目录 original/、输出目录 dxf/，输出版本选 ACAD2018，输出类型选 DXF，勾选递归和审计，再点 Convert。
  3. 转换失败的单个文件会留在列表里。记下文件名和报错，不要默默跳过。

更底层的备用是 Homebrew 的 libredwg（brew install libredwg，再用 dwg2dxf）。它对旧版本 DWG 支持较好，但质量不如 ODA，只作为最后手段，结果要逐张核对。

4. 准备 Python 环境

三个脚本需要 Python 3.9 以上，首次先准备一次环境，以后直接用。

  1. 在「终端」输入 python3 --version。没有 Python 时，从 Python 官方下载页安装 macOS 版。
  2. 在 CAD-Review/ 里建独立环境并安装依赖：
python3 -m venv .venv-cad
.venv-cad/bin/python -m pip install -r tools/requirements.txt
  1. 更省事的做法：把下载的三个脚本和 requirements.txt 放进 tools/，再用下面这条提示词让 Harness 建环境、装依赖并报告结果。它做完后，你打开终端核对一次输出。
提示词
当前工作区是 CAD-Review/。请只做三件事，不要动 original/ 里的任何文件：
1. 只读查看 tools/，确认 cad_inventory.py、make_review_sheet.py、make_sample_pfd.py 和 requirements.txt 已就位；
2. 用 python3 -m venv .venv-cad 建环境，并按 tools/requirements.txt 安装依赖；
3. 运行 .venv-cad/bin/python --version 和 .venv-cad/bin/python -c "import ezdxf"，把两条命令的实际输出和失败信息原样报告给我。

下载：示例 DXF · cad_inventory.py · make_review_sheet.py · make_sample_pfd.py · requirements.txt

5. 先在虚构示例上跑通

示例是一张虚构的「糖浆配制工艺流程图」，设备位号和流程都不对应任何真实装置，可以放心练。

  1. 把 sample-pfd.dxf 放进 sample/。
  2. 运行清单脚本，看它生成了什么：
.venv-cad/bin/python tools/cad_inventory.py sample/sample-pfd.dxf -o inventory
  1. 打开 inventory/sample-pfd.md，应该能看到图框文字、图层表、设备和仪表清单。再打开同名 .json，看每条记录都带一个 handle。
  2. 如果终端出现「读取失败」「编码」或「外部参照」的提醒，先记下来，不要急着换图。

6. 换成自己的一张图

  1. 把第 2 步另存出的 DXF 放进 dxf/，先只放一张。
  2. 对 dxf/ 整个目录运行同一个脚本。目录模式会额外生成台账 ledger.csv：
.venv-cad/bin/python tools/cad_inventory.py dxf/ -o inventory
  1. 打开 inventory/<图号>.md，先看最上面的「需要先看的问题」，再看设备、仪表、图层和文字。
  2. 中文出现乱码时，先换 ODA 输出一次 ACAD2018 再试；仍然乱码，就加 --encoding gbk 重跑，并把结果记进 notes/。

7. 让 Harness 只复述清单里的内容

把清单交给 Harness，但先把规矩说清楚：只根据文件内容回答，每条注明来源，不确定就写「无法从文件确认」。

提示词
当前工作区是 CAD-Review/。请只读 inventory/ 里的清单文件，先报告你实际打开了哪几个文件、每个文件多少行。
然后只根据这些文件内容回答：
1. 图框里的图名、图号、版本、日期；
2. 图层清单和每个图层的实体数；
3. 设备位号与名称；仪表位号与名称；
4. 位号候选里哪些像管线号、哪些像设备或仪表位号。
每条结论后面注明它来自哪条文字或哪个 handle。文件里没有的，写「无法从文件确认」，不要补猜，也不要评价工艺是否合理。

8. 亲手核对，再决定下一步

打开 AutoCAD 原图，逐项对照清单。核对不上的写「待核对」，不要写成通过。

核对什么 清单里怎么写 原图里怎么看 结论
图名与图号 标题栏文字的 handle 打开图框逐字对照 通过 / 待核对
设备位号 设备清单的 TAG 与 handle 在图上找到该位号 通过 / 待核对
仪表位号 仪表清单的 TAG 与 handle 对照仪表圈和引线 通过 / 待核对
数量 设备、仪表、文字条数 抽一类数一遍 通过 / 待核对
图层 图层表与实体数 图层管理器里对照 通过 / 待核对

核对完在 notes/<图号>-阅读.md 里记一句：这张图能不能被完整读出、哪些内容没读到、下次要不要重新另存。

完成时，爸爸应该能说清三件事：DXF 是从哪张原件怎么来的；清单里哪些是文件原文、哪些是脚本推断；Harness 的哪条结论能指回具体的 handle。

检查清单

  • CAD-Review/ 的七个目录已经建好，原件只读。
  • 至少一张图已另存为 AutoCAD 2018 DXF，文件名用图号。
  • 外部参照已绑定，或已在 notes/ 记录未绑定的情况。
  • .venv-cad 能运行，import ezdxf 成功。
  • 虚构示例跑通，inventory/sample-pfd.md 里有设备和仪表清单。
  • 自己的一张图生成了清单和台账，warnings 已逐条看过。
  • Harness 的复述能指回 handle，且没有补猜。
  • 至少核对了图号、三个位号和一个数量，结果记进 notes/。

隐私提醒：真实图纸的文字可以交给模型讨论，但图纸原件、审图页和核对记录都留在本机 CAD-Review/；公开课稿、截图和课程仓库只用虚构示例。第 11 节做批量台账，第 12 节在 Harness 里浏览和标注。
