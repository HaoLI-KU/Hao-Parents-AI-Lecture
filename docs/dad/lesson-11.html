Lesson 11 · 爸爸

先建台账，再让 AI 只列疑点

批量生成台账，让 AI 只列跨图疑点，逐条判定并沉淀核对规则

本节步骤

01一次只放 3–5 张图02批量生成清单和台账03让 Harness 做跨图核对，但只列疑点04逐条判定，写证据05把能重复的规则留下来06这一节做到哪里算完成07检查清单

第 10 节读懂了一张图。真正要整理的是很多年、很多套装置的一批图。这一节把「一张一张看」变成「先有一份台账，再有跨图核对」，并且把 AI 的角色压在只列疑点、不下结论这一侧。

工艺判断仍然由你做。AI 能做的是把散在各张图里的位号、图层和图框文字并排放在一起，指出哪里不一致，再去原图核对。

1. 一次只放 3–5 张图

  1. 从同一套装置或同一阶段里挑 3–5 张有关联的图，例如总流程、反应、分离各一张。先不要一次放几十张。
  2. 每张图按第 10 节的方法另存 DXF，文件名统一用图号；图号里不要有空格和斜杠。
  3. 在 notes/<图号>-阅读.md 里各写一行：这张图是什么、和图里哪几张相关、有没有未绑定的参照。

2. 批量生成清单和台账

把这一批 DXF 一起放进 dxf/，对目录运行清单脚本：

.venv-cad/bin/python tools/cad_inventory.py dxf/ -o inventory

脚本会为每张图生成一份 .md 和 .json，并在 inventory/ledger.csv 里汇总一张表：

列 含义 先看什么
file 文件名 是否都用图号
dxf_version DXF 版本 是否统一到 AC1032（R2018）
entities 实体总数 数量明显偏少的图要单独看
texts 文字条数 太少可能是参照没绑定
equipment / instruments 设备、仪表数 与印象差太多时先核对
tags 位号候选数 用于发现漏提取
warnings 提醒条数 不为 0 的图先处理

台账不是结论，只是「这批图能不能读、读到了多少」的体检表。warnings 不为 0 的图，先在原图里处理外部参照或重新另存，再进入下一步。

3. 让 Harness 做跨图核对，但只列疑点

先把要求说死：只列需要你确认的项目，每条给证据，不判断对错、不评价工艺。这样它不会用「看起来合理」的猜测混进台账。

提示词
当前工作区是 CAD-Review/。请只读 inventory/ledger.csv 和 inventory/ 里这一批图的清单（.md 与 .json），不要打开也不修改 original/ 和 dxf/ 里的图纸。
请做一次跨图核对，但不要下结论。只列需要我人工确认的项目，分四类：
1. 同一位号在不同图纸里名称、参数或位置不一致；
2. 设备或仪表位号重复、跳号、或只出现在一张图里；
3. 图层命名、图框版本、图号格式不一致；
4. 清单里读不到或可能缺内容的地方（外部参照、代理对象、编码问题）。
每条写清：疑点是什么、证据（文件 + handle + 原文）、为什么值得核对、建议我在原图里看哪里。
没有把握的写「待确认」，不要编造位号，也不要替我判断工艺是否合理。
最后列出你认为我应该先核对的三条，并说明理由。

4. 逐条判定，写证据

在 notes/ 新建 cross-check-<日期>.md，把 AI 列的每一条抄进去，逐条判定：

判定 什么情况用 记录要写什么
成立 原图确实是那样 图号、handle、原图位置、你的判断
不成立 清单提取或 AI 理解有误 错在哪：文字、块、图层还是推断
需原件确认 本机副本看不清或版本不对 缺什么、去找哪份原件

判定原则和第 9 节一样：没核对到的写「待核对」，不填「通过」。AI 说「疑似缺一个回流泵」，你要回到 PFD 上确认管线走向和泵位号，不能因为它说得顺就采纳。

5. 把能重复的规则留下来

跑完两三批图，你会发现自己反复在核对同样的东西。这时再写 standards/cad-review.md，只写已经确认的规则；不确定的标「待定」。

# standards/cad-review.md｜图纸核对规则
- 位号格式：设备用「字母-三位数字」，仪表用「两位功能字母 + 编号」；以本装置现有图纸为准。
- 图号与文件名一致；另存 DXF 统一用 AutoCAD 2018 DXF。
- 先绑定外部参照再另存；有未绑定参照的图不进入跨图核对。
- 文字编码：R2004 及以前用 $DWGCODEPAGE，出现乱码先用 ODA 重出 ACAD2018。
- 清单 warnings 不为 0 的图先处理，不进入下一步。
- AI 只能提出疑点；每条结论必须能指回「文件 + handle + 原文」。

规则写短。它是给下一次会话和你自己看的，不是给外人看的制度文件。

6. 这一节做到哪里算完成

完成时，你应该能展示：一批 3–5 张图的台账、一份逐条判定过的跨图核对记录、一份只写确定规则的 standards/cad-review.md，并能说清哪几条是 AI 找出来的、哪几条是你自己核出来的。

检查清单

  • 这一批 3–5 张图都按图号命名并另存为 DXF。
  • ledger.csv 已生成，每张图一行。
  • warnings 不为 0 的图已处理或已记录原因。
  • 跨图核对结果只包含「疑点 + 证据 + 建议核对位置」。
  • 每条疑点都有「成立 / 不成立 / 需原件确认」的判定。
  • standards/cad-review.md 只写已确认规则，未确定的标「待定」。
  • 没有把 AI 的推测当成工艺结论。

第 12 节把审图页打开，在 Harness 里直接点选和批注。
