认识 AI：按爸爸第 1 节做

按爸爸第 1 节：认识 AI 与 DeepSeek/Codex

这一节和爸爸第 1 节是同一份内容。打开爸爸第 1 节，按那里的步骤做；账户、API Key 和登录都用自己的，不要用爸爸的密钥。

  1. 先读爸爸第 1 节的「用两层来理解 AI」，用自己的话说出界面和模型的分工。
  2. 按爸爸第 1 节创建或登录自己的 DeepSeek 开放平台账户，按页面提示小额充值。
  3. 创建自己的 API Key，接到这台 Mac 的 Codex 上，发一条测试，再回开放平台核对用量。若这台 Mac 还没有 Codex，先和爸爸一起按第 1 节的入口装好。
  4. 完成后记下卡住的一步；下一节用 Harness 继续。

备查：DeepSeek 开放平台 · DeepSeek Codex 接入说明
