推理强度、用量与查网页：按爸爸第 3 节做

按爸爸第 3 节：推理强度、用量与查网页/日历

打开爸爸第 3 节，用同一道题比较推理强度，回开放平台看用量，再用 Harness 读公开网页和只读日历。

  1. 在 Harness 里找到模型名和 Effort。
  2. 用爸爸第 3 节的虚构行程题，分别用 low 和 high/max 各做一次。
  3. 回 DeepSeek 开放平台核对两次请求的用量。
  4. 用微信输入法口述一条提示词，按爸爸第 3 节读一条公开网页；日历只读，不创建或修改日程。
