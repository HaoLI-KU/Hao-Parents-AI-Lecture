妈妈的课程/第 7 节

Lesson 07 · 妈妈 · 上海家中

补练与验收：把前六节的操作连起来

本节步骤

01先自己走一遍清单02卡住时只补一小步03收尾

这一节不加新工具。把前面用过的东西自己走一遍，哪里卡住就记下来，再决定下一节从哪继续。

1. 先自己走一遍清单

逐项做，做到就在方框里记一下；没做到写下停在哪一步。

  • 腾讯会议：从邀请链接入会，开关麦克风，共享一个练习窗口，再退出重进。
  • 邮件：用苹果「邮件」发一封测试邮件，在 126 网页邮箱的「已发送」里找到；请家人回一封，再在苹果「邮件」看到。
  • 日历：新建一个带开始和结束时间的测试日程，放进家人共享的日历，请家人在另一台设备确认。
  • 备忘录：在 iCloud 备忘录里找到家人共享的三条，打开其中一条看到正文。
  • 相册：在「照片」的「共享」里打开一张家人分享的照片。
  • 快捷键：⌘C 复制、⌘V 粘贴、⌘S 保存、⌘W 关窗口、⌘Q 退出、⇧⌘4 区域截图。
  • 语音输入：用微信语音输入或苹果听写写一行中英混合的文字。
  • MacTeX：用 TeXShop 打开第 4 节的 main.tex，按「排版」生成带目录和两个中文章节的 PDF。
  • 豆包屏幕共享：发起语音通话并共享练习画面，问一个小问题，照它说的做一步，再停止共享。

2. 卡住时只补一小步

从清单里挑一项没完成的，按这个顺序处理：

  1. 先说出眼前看到什么、点到了哪一步。
  2. 只问一个小问题，例如「这个窗口的下一步点哪里？」
  3. 自己照着做一步，再核对结果。
  4. 还是不行就记下应用名、窗口标题和提示文字，下次从这一步继续。

收尾

完成时，至少会议、邮件和文件操作能独立走通；没完成的项目写在本机清单里，不带进养花小站。下一节开始装 DeepSeek Harness，做「我的养花笔记」。
