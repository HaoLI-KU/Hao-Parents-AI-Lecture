把一次出门安排明白

用行程规划插件做一日行程

从「3 个人、9 点出门、想去温室和吃日料」到候选、小时表和 zine 网页；每一轮都标清你做还是 AI 做。

3 讲
第 1 讲你先开口，AI 给候选共同→第 2 讲AI 排到小时，你核对和订位共同→第 3 讲AI 做成网页，你检查保存共同→

专题说明

这套专题按三轮走，每轮只上升一个粒度：你写条件、发 prompt，AI 查证和给候选；你选，AI 排到小时；你核对和订位，AI 做成网页；最后你检查、保存。案例是 3 个人从中山公园出发的上海一日，每一步都标了「你做」还是「AI 做」。
